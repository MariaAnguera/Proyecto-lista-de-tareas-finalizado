# ✅ Gestor de Lista de Tareas (Task Manager)

Aplicación web interactiva diseñada para la gestión eficiente de tareas diarias, enfocada en la productividad y en ofrecer una interfaz de usuario limpia, intuitiva y fluida.

## 🚀 Características principales
* **Creación y Gestión de Tareas:** Permite añadir nuevas tareas, marcarlas como completadas o eliminarlas de forma dinámica.
* **Interfaz Interactiva:** Actualización de elementos en tiempo real mediante manipulación del DOM y eventos en JavaScript.
* **Diseño Adaptativo (Responsive):** Maquetación cuidada para garantizar una experiencia cómoda tanto en dispositivos móviles como en ordenadores de escritorio.

## 🛠️ Tecnologías utilizadas
* HTML5
* CSS3 (Estilos limpios y diseño personalizado)
* JavaScript (ES6+ para la lógica de la aplicación y gestión de estados locales)
* Git y GitHub (Control de versiones)
